## 大任务：可替换真实模型接入的 work order

之前讨论的顺序就是该大任务的拆分。每步完成标准见对应周子目标：

1. **结果契约与输入分类**（W1.1）：定义 extracted / estimated / unknown，细到用量等字段。
2. **选 VLM、实现供应商适配**（W1.2）：统一输入输出，密钥仅服务端。
3. **固定文字+图片真实运行**（W1.2）：保留输入、原始响应和校验结果。
4. **知识辅助补全**（W1.3决策 → W2.1实现）：明确知识来源与预估依据，不伪造原文证据。
5. **四类 eval 与修正**（W1.5定义范围 → W2.4初评 → W3.4验收）：通过阶段质量检查后才认定真实能力交付。
6. **真机接入**（W2.2–W2.3）：可按已定契约并行开发；真实模型未通过评估时，只能算联调，不能算质量达标。

2026-10-02：已决定建设知识库，缺失时通过Wikipedia/烹饪网站API补充并更新；提供方、存储实现与入库门槛待定，代码未实现。Agent构建方式与VLM选择仍待确认。
